# Stellar Burgers: юнит-тесты

Первое задание дипломного проекта. Тесты написаны на Python с использованием
`pytest`, `pytest-cov` и `unittest.mock`.

Проект входит в комплект заданий для
[QA-стенда Stellar Burgers](https://qa-stellarburgers.education-services.ru/).
Юнит-тесты проверяют локальный класс Burger и не выполняют запросы к веб-стенду.

## Установка и запуск

Нужен Python 3.10 или новее. Выполняйте команды из корня этого репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest
```

В Windows активация окружения: `.venv\Scripts\activate`.

Команда запускает тесты и проверяет покрытие строк и ветвей **всего пакета
`praktikum`**. В `pytest.ini` установлен порог 100%: при меньшем покрытии запуск
завершается ошибкой. Отчёт выводится в терминал и сохраняется в
`htmlcov/index.html`. Копия отчёта для ревью сохранена в `reports/coverage/index.html`
и включена в пул-реквест. Виртуальное окружение не включается в Git.

После разделения проверок повторно проверено на Python 3.13.5:
**51 тест прошёл**, из них 35 проверяют Burger. В каждом тесте одна проверка;
проверки вызовов моков вынесены в отдельные тесты.
Покрытие пакета и отдельно модуля Burger — **100% строк и ветвей**.

Запуск только тестов Burger с отчётом по его модулю:

```bash
python -m pytest tests/test_burger.py --cov-reset --cov=praktikum.burger
```

Запуск демонстрационной программы:

```bash
python -m praktikum.praktikum
```

## Что проверяется

- `Burger`: начальное состояние и независимость экземпляров, выбор и замена
  булочки, добавление ингредиентов и дубликатов, удаление первого, среднего,
  последнего и единственного ингредиента, перемещение в обоих направлениях
  и на ту же позицию.
- Цена: две половины булочки, отсутствие ингредиентов, один и несколько
  ингредиентов, повторяющиеся ингредиенты, нулевые и дробные цены.
- Чек: точный текст и переносы строк, типы `SAUCE` и `FILLING` в нижнем регистре,
  порядок ингредиентов, актуальная сумма после перемещения и удаления,
  названия на кириллице.
- `Bun`, `Ingredient`, `Database`: получение значений и содержимое каталога.
- Демонстрационный сценарий: запуск функции и модуля с проверкой напечатанного чека.

В тестах Burger зависимости `Bun` и `Ingredient` заменены моками с `spec`.
Общие фикстуры находятся в `tests/conftest.py`, варианты данных задаются через
`pytest.mark.parametrize`.

## Структура

```text
praktikum/          # Исходный код заготовки, собранный в пакет
tests/              # Тесты и фикстуры
pytest.ini          # Настройки запуска и покрытия
requirements.txt    # Версии зависимостей
```

Логика исходной программы сохранена; файлы перенесены в пакет `praktikum`,
чтобы существующие импорты работали. Ветка для сдачи — `develop1`.
